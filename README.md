# Projeto de Estudo em Java

Este projeto foi criado para registrar e praticar os conceitos básicos da linguagem Java durante o estudo da linguagem.

## Descrição

O objetivo deste repositório é servir como material de apoio para revisão de fundamentos da linguagem Java, com exemplos simples e estudos práticos focados em sintaxe e lógica.

## Estrutura do projeto

- `src/Variaveis.java` — estudo sobre declaração, tipos e uso de variáveis.
- `src/LogicaBasica.java` — exemplos de lógica de programação com estruturas básicas.

## Conteúdo abordado

### 1. Variáveis
- Tipos primitivos
- Declaração e atribuição
- Operações simples

### 2. Lógica Básica
- Estruturas condicionais
- Laços de repetição
- Fluxo de execução e tomada de decisão

### 3. Em progresso
- ...

## Como executar

Compile os arquivos Java com:

```bash
javac -d out src/*.java
```

Em seguida, execute a classe principal desejada:

```bash
java -cp out <NomeDaClasse>
```

## Objetivo

Este projeto é uma base inicial de estudo para consolidar os primeiros conceitos da linguagem Java e evoluir gradualmente para tópicos mais avançados.
